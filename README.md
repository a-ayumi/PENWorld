# PENWorld — PULSAR

手のひらサイズの 3D 液晶ペット。机の上や電車の中に浮かぶ本体の画面の中で、PS1 風の 2.5D 箱庭に住むオリジナルのモンスターたちが、自分で歩き・食べ・眠り・遊び・戦い・仲間になり・たまごを産んで暮らします。
人は直接操作せず、食べ物や置き物を用意して見守ります。スマホの PWA としてオフラインでも遊べます。

## 遊び方
| ボタン | 動き |
|---|---|
| A | アイコンをえらぶ（ショップ内では商品をえらぶ） |
| B | けってい（何も選んでいない時はステータス） |
| C | もどる（キャンセル） |
| 画面に入る | 下の「▶ 画面に入る」ボタン（パソコンは Enter）。出る時は「本体にもどる」（Esc） |

画面のアイコンやショップの項目は**タップでも操作できます**（ショップは「選んで、もう一度タップで購入」）。右上の「視点」で みおろし / ペットのうしろ / ペットのめせん、「音」で音量（切・小・中・大）を切り替えられます。**2 本指でピンチすると寄る・引く、2 本指でドラッグすると前後左右に動かせます**（パソコンはホイールと矢印キー）。画面の何もない所をタップすると、文字やボタンを全部かくして景色だけを眺められます（もう一度タップで元に戻る）。

キーボードは `A` `B` `C`（`Z` `X`、`1` `2` `3` でも可）、視点は `V`。本体はドラッグで傾けられます。左上の「きせかえ」で本体の柄・いる場所・キャラの表現（ドット / ポリゴン）を選べます。

## 主な要素
- ステージ 5 種：はじまりの森 / ガラスの砂丘 / さんごの入り江 / わたゆきの原 / こおりの回路峰
- 追加ステージ 2 種：ほむらのかざん（溶岩・黒曜石・噴煙・火の粉）/ こだいのいせき（苔むした石畳・浮かぶ石板・夜に光る文様・霧）
- モンスター 14 種：仲間になれる 10 種（4 段階の進化）＋ 敵 4 種（ノイズ / トゲバグ / 夜だけ出るヤミカゲ / 家をこわすゴウガン）
- 食べ物と行動で育つ傾向（ちから / まもり / こころ）による進化分岐
- 種族ごとの技（技名つきの演出）。バトル中に「バトル」を押すと おうえん で技を出す
- 1 匹ずつ別々に進化（性格と、戦う・建てる・遊ぶなどの行動で分かれる）、じゃれあいバトル
- 木や石を集めて家を建てる（敵にこわされたら直す）、天気（はれ・くもり・あめ・ゆき・ひのこ）
- 天気で地形も変わる：風に木や草がゆれる／あめで地面がぬれて水たまり・波紋・しぶき・雨あがりのにじ／ゆきで少しずつ積もる／ひのこは熱で空気がゆらぐ／朝もや・雲の影・水面のきらめき・月と星の移動（画質「低」では軽くなる）
- 仲間・たまご・こども、コインとショップ（なえ・ボール・たき火・おまもり・ざいもくセット・だいくどうぐ・まもりのさく）
- 系統：きかい・りゅう・ねこ・いぬ・とり・みず・モンスターの 39 種が新登場。赤ちゃん → 成長期 → 成熟期 → 完成期に、育て方で枝分かれして進化
- たまごの種類：系統ごとに色が違い、ショップで買う・野原で見つける・親の系統を受けつぐ（ときどき突然変異）
- ずかん（仲間 49 種 + 敵 4 種）／仲間の役割分担（だいく・はたけがかり・みはり）／ペットの世代交代（じゅみょう → おはか → 生まれ変わり）／かいたく（箱庭が 20 → 26 → 32 に広がる）
- 本体のかたちを選べる：かわいい系（くま・おはな）、きかい系（ロボ・メカ）、まる（たまご）。きせかえの「本体のかたち」から
- 背景の場所は、手に持って（すわって）遊んでいる景色：電車の座席・通学路・教室の机・バーガーショップのテーブル・公園のベンチ（机の上は立てかけ）
- 箱庭の物をタップすると情報が出て、家・建物・置き物・たまごは「かいたい」「かたづける」で消せる（資材がのこる）
- はじめは、ペットと てきだけ。仲間は 野原のたまご や ショップのたまごから
- 建築：はたけ・いど・ゆりかごごや・はし・みはりとう・おしろ（へいで囲まれる）を、ショップの「せっけいず」で計画 → みんなが資材を運んで建てる。家は増築までできて、建物が集まると むら → まち → じょうかまち に
- 動き：歩くと弾み、息をして、着地でつぶれる／かなづちでトントン建てる／建った瞬間ぽよん／えんとつのけむり／旗がゆれる／ちょうちょ（昼）とほたる（夜）／ヒットストップ
- てきぐんが ときどき攻めてくる。ペット・仲間・みはりとうが迎えうつ
- キャラの見た目：個体ごとのもよう（ぶち・しま・そばかす・ほっぺ）と色のゆらぎ／約 3% で ★ の色ちがい（ずかんに別記録）／おなかすいた・ねむい・うれしい・おこっている・こまっている の表情／進化は白いシルエットが光ってふくらむ演出／敵の亜種 6 種と、3 回に 1 回のボス（専用の大きな姿と大きな HP バー）
- ごはん・ねむり・トレーニング・あそび・家づくりのあとに、何がどれだけ増えたかをメッセージで表示（例：「おなか+50 きげん+10」）
- 仕上げ：画質 高/低/自動、裏に回ると止まる、せってい（文字の大きさ・動きをへらす）、初回の遊び方、新バージョンのお知らせ、オフライン起動
- iPhone のホーム画面に箱庭を：アプリ「Scriptable」で ウィジェット（小・中・大）。きせかえ → ウィジェット →「スクリプトをコピー」を Scriptable に貼りつけて名前を PULSAR に →「ウィジェットに送る」→「Scriptable をひらく」。景色は送った時のもので、生き物は 15 分ごとに時刻に合わせて動く（夜はねる・ほたる）。ペットは時間がたつと おなかがすく・ねむくなる・さみしくなり、表情とポーズが変わる。中・大の「ごはん」「なでる」でお世話できる。タップで PULSAR がひらく
- 自動セーブ（端末の localStorage）。きせかえ → データ で「書き出す」「読み込む」（別の端末への引っこし・バックアップ）、「最初からやり直す」（2 回押し）

## 開発
```bash
npm install
npm run dev       # 開発サーバー（同じ Wi-Fi のスマホからも開ける）
npm run build     # 型チェック + 本番ビルド（dist/）
npm run preview   # 本番ビルドで PWA / オフライン動作を確認
```

`main` に push すると GitHub Actions がビルドして GitHub Pages に公開します（Settings → Pages → Source を「GitHub Actions」にしておく）。公開ページはスマホでホーム画面に追加すると PWA としてオフラインでも遊べます。

# はじめに読む：Antigravity で次のゲームを始める手順

## 1. この知恵袋を置く

- このフォルダ（`gamedev-kit`）をデスクトップなど好きな所に置いておく。
- 新しいゲームのフォルダを作ったら、その中に `docs/kit/` などの名前でコピーしておくと、AI がいつでも読める。

## 2. AI へのルールを入れる

`templates/AGENTS.md` を新しいプロジェクトの一番上（ルート）にコピーして、ゲームの名前と中身を書きかえる。

- Antigravity には「ルール（Rules）」や「ワークフロー（Workflows）」を登録する仕組みがある。
  `AGENTS.md` の中身を、そのワークスペースのルールにも貼っておくと確実（置き場所や読みこまれ方は Antigravity の版によって変わるので、画面の設定で確かめる）。
- PULSAR ではこの紙を `CLAUDE.md` という名前で使っていた。名前は何でもよい。大事なのは
  **「コマンド」「どこに何があるか（ファイルの地図）」「守るルール」「確かめ方」**の 4 つが 1 枚にあること。

## 3. 計画の紙を作る

`templates/PLAN.md` をコピーして `docs/PLAN.md` に。
- 方針（何のゲームか・何が主役か）
- 段階の表（A, B, C … の段と、済み / のこり）
- まだマージされていない作業
を毎回書きかえる。新しい会話はこの紙を最初に読ませる。

## 4. 最初にエージェントへ頼むこと（例文）

```
docs/kit/README.md と 01_進め方.md を読んで、その進め方で進めてください。
まず AGENTS.md と docs/PLAN.md を作り、デバッグの入口（window.__ゲーム名）と
早送りできる update(dt) を用意してください。見た目は見本を 1 つ作って見せてください。
```

## 5. 確認の道具を用意する

`tools/` の Playwright スクリプトを `tools/test/` にコピーして、ゲームに合わせて名前を直す。
- `smoke.cjs`：早送りしてエラーが出ないか
- `run2.cjs`：好きな JS を走らせる → セーブ → 読みなおし
- `capture.cjs`：同じ乱数で同じ場面を作って撮る
- `sprites.cjs`：キャラの一覧を 1 枚に
- `reach.js`：歩いて行けない平らな所が無いか
- `frames.sh`：見本の動画をコマに切る（ffmpeg）

## 6. 注意（AI ツールを変えても同じ）

- AI はセッションが切れると細かいことを忘れる。**紙に書いたことだけが残る**。
- 「全部進めて」と言った時も、AI にはまず計画（段・中身・見積もり）を出させる。
- 寝る前に任せる時は「何を・どこまで・どう確かめるか」を一言そえる。終わったら報告の「確かめていないこと」を読む。

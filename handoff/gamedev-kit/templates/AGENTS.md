## ルール
- **デザインはすべてオリジナル**。実在のゲーム・キャラ・ロゴ・UI・効果音を再現しない。雰囲気と技法だけ取り入れる
- **1 PR = 1 テーマ。出した PR にあとからコミットを足さない**（追加は新しい PR。前の PR が未マージならその上に重ね、「この PR だけで #○○ も入ります」と書く）
- 作業の最初に、前の PR がマージされたかを調べる
- 見た目を変えたら **スクリーンショット（1280×800 と 390×844）を撮って自分で見てから** 完了とする
- 遊びの調整は **早送りで数を測ってから**。直したら同じスクリプトで測りなおす
- 報告は「変えたこと → 確かめたこと → **確かめていないこと** → 次」
- 重い効果は画質「低」で切れるようにする
- セーブ項目を増やしたら保存と読み込みの両方を直す。読み込んだデータは信用せず範囲を検査する
- **セキュリティ**：秘密・鍵・個人情報をコミットしない。外部通信を増やさない。`innerHTML` に外部の文字を入れない
- 色・大きさ・速さなどの数は名前をつけて 1 か所に（調整が 1 行ですむ）

## デバッグの入口
- `window.__（ゲーム名）`：`.world` / `.state()` / `.press(…)` など
- `world.update(dt)` を描画なしで回せば早送りできる

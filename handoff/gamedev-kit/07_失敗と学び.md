# 07 失敗と学び（早見）

| 起きたこと | 学び |
|---|---|
| 出した PR にあとからコミットを足したら、足す前にマージされて「入ってない」（3 回） | 出した PR には足さない。追加は新しい PR |
| 島を広げたのに「狭い」と言われた | マージに入ったか、まず調べる |
| テストでは宝箱が開くのに、遊ぶと開かない | 確率まかせにせず、人が触れる入口（タップで開けに行く）を作る |
| 段差で動けなくなる | のぼり / おりを分ける + はまったら出す |
| 岩が緑に見える | 色をテクスチャにかけていた。材質を分ける |
| 目を大きくしたら悪くなった | 一覧で前後を見比べてから入れる。だめなら入れない |
| 進化が色ちがいに見える | 形・大きさ・飾りを段階で変える |
| 生き物をなめらかに描いたら「きもちわるい」 | リアルに寄せない。まるい体・大きな頭・短い手足 |
| 3D のキャラが「ゴツゴツ」 | 頂点スナップと光の段を外したやわらかい材質 |
| 木が「ポリゴンっぽい」 | 面ごとの色をやめ、球の陰 + でこぼこ + 葉の房の模様 |
| 木が大きすぎる（2 回言われた） | 大きさは定数 1 つに。言われたら 1 行で直す |
| 見本と「何が違う？」→ 5 つ挙げたら「質感じゃない？」 | 違いを並べて見せ、人に一番を選んでもらう |
| 画質の悪い見本で「平らな塗り」と判断 → きれいな版では描きこみがあった | 見本はできるだけ画質の良い版で。判断がひっくり返ったら素直に直す |
| 坂の川がうろこ模様 | 小さな水面の重ねをやめ、1 枚の水面に |
| 早送りで「全員腹ぺこ」 | 早送りの 1 歩が大きすぎて食べ物が着地しなかった。ふつうの歩幅でも測る。跳ねる判定を 1 歩の大きさに比例 |
| 食べ物は山ほどあるのに、なかまが倒れる | 城の壁ぎわ（当たりの中）に落ちた食べ物を目指し続けていた。落とす場所を選ぶ・2 回失敗で片づける |
| 雨と夜が続くと腹ぺこのまま | `think()` の順番。とても腹ぺこなら休むより先に食べる |
| 戦争が 2 時間決着しない | 新しいゲームのまま長く早送りして、ログと 1 匹の追跡で原因を 1 つずつ |
| ビルドが CI だけ落ちる | 手元も CI と同じ入れ方（`npm ci`）で |
| SNS のページが読めない | 画面録画をもらい、コマに切って見る |
| フラグメントシェーダーで `projectionMatrix` が使えずエラー → 水が消えた | シェーダーのエラーはコンソールに出る。ブラウザのログを見るスクリプトを持つ |
| 使われない遊び（おねがい・目標・くじ・ひみつ）が増えた | コードは残してゲームから外す。作ったものに固執しない |
| スマホが熱い | 1 秒に描く回数をしばる・さわらないと半分・重い効果は低画質で切る |

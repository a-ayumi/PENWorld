# 06 ゲームの仕組み：放置して眺めるシミュレーション

PULSAR は「人は直接操作せず、環境を用意して見守る」ゲーム。アリの巣が育つのを眺める感じ。
キャラは自分で考えて動き、町は勝手に育ち、戦争も自動。

## 1. キャラの考え（think）

- 状態（idle / walk / eat / sleep / build / fight …）と残り時間を持たせ、時間が切れたら `think()` で次を決める。
- `think()` は **上から順に** 決める。**順番がそのまま優先順位**：
  戦争の部隊 → 敵が来た → 身を守る → **とても腹ぺこ** → 雨・夜は休む → 宝箱 → 遊び → 腹ぺこ → 眠い → 仕事（建築・畑・見張り）→ ぶらぶら
- 順番のミスは大きなバグになる：「雨・夜は休む」が「食べる」より上にあると、夜や雨が続いた時に **腹ぺこのまま休み続ける**。
  → とても腹ぺこ（25 未満）だけは休むより先に食べに行く。
- 暇な時の既定の行動は「建築・修理」。やることが無ければ自分たちで畑や井戸を計画する。

## 2. 役割分担

- 15 秒ごとに、性格と町に足りない物から役割を決める（だいく・畑係・見張り・ごはん係・石工 …）。
- 頭の上に色つきの点。タップすると役割と「いま何に向かっているか」。
- ペット（主人公）だけ人が「方針」を選べる（戦い優先・建築優先・木と花・城壁）。人の関わりは間接的に。

## 3. 町が育つ

- 資材を運ぶと城に部屋が増える（部屋 1 つ = 家 1 軒の点）。点数で **時代** が上がる（のじゅく → 丸太 → 木組み → 石の城下町 → 城 → 白い城 / じょうきの町 …）。
- 時代ごとに建物・城壁・門の形が変わる。古い物は **古びる**（こけ・ひび → くずれる）。
- 引っ越し：空き部屋があると、よその地方の子が歩いてきてなかまになる。
- 育つ速さは早送りで測って調整した（時代 2 = 3〜5 分 / 城 = 35〜40 分 / 6 段 = 55〜85 分）。

## 4. 食べ物の流れ

- 食べ物は木や畑のそばに実る。なかまの数で増える（1 匹 1 分に 1 個ほど食べる）。
- ごはん屋：ごはん係が運んで手渡し、余りはためる。
- **落とす場所に気をつける**：建物の当たりの中・歩けない所には落とさない。取りに行って **2 回たどりつけなければ片づける**（同じ物を目指し続けて倒れていた）。
- 落ちる・跳ねる判定は 1 歩の大きさに比例させる（早送りで着地しなかった）。

## 5. 戦争（全部自動）

### 形
- 3×3 の地方。味方の町（左下）と敵の町（右上）、ほかの 7 地方の真ん中に **拠点**（旗 = 青 / 赤 / 灰）。
- 味方も敵も、ときどき部隊（3〜6 匹）を出して「自分の陣地のとなり」の拠点を取りに行く。
- 拠点のまわりに相手がいないまま部隊がいると取れる。取った拠点から町へ資材・食べ物・その地方の子が届く。

### 決着
- 敵の城のとなり（斜めも）の拠点を持ち、敵の城が育っていると **城攻め**。城（城壁があれば外の城壁）の手前でたたく。
- 城の体力は部屋の数で増える。**回復はとてもゆっくり**（何回かの攻撃でけずりきる）。敵は守りを少し出す。
- **勝つ**と：敵の城と城壁はそのまま **味方の 2 つめの町** に・拠点は全部味方・花火・「しょうり！」・お祭り・20 分の平和。
- 平和が終わると、一番遠い陸の地方に **新しい敵の町** が 1 部屋から育つ（次の戦争）。
- 味方の負けは無い（のんびり見ていられる）。

### 調整で分かったこと（新しいゲームを 120 分早送りして）
| 起きていたこと | 直し方 |
|---|---|
| 部隊が出て 10 秒でばらける | 選ぶ時に「おなか・ねむけに余裕がある子」だけ。帰る基準は低く |
| 取った拠点をすぐ取り返される | 取った部隊は 1 分その拠点を守る |
| 城攻めに行けない（敵の城のとなりは敵がずっと持っている） | 真ん中の丘（斜めのとなり）からも行ける |
| 城攻めで体力が 1 度も減らない | 城壁があれば外の城壁をたたけば城が減る |
| 半分まで減ってまた戻る | 回復を 20 分で元どおりに（とても遅く） |
| 小さな部隊が守りと戦うだけで城に届かない | 守りを 20 秒ごと 1 匹・4 匹まで |
| 結果 | 1 回目の勝ち 約 55 分・2 回目 約 100 分（1 回の早送り） |

## 6. セーブ

- セーブする物 / しない物を分ける。見た目だけの物（町の飾り・道の石）は状態から作り直す（種 = 場所）。
- セーブを増やしたら **保存と読み込みの両方** を直す。
- **読み込んだ物は信用しない**（種族の名前・数の範囲を検査）。
- 留守の間は早送り + 数式で圧縮（上限 8 時間）。「おかえり」で何が起きたかを見せる。

## 7. 人がやること（間接的な関わり）

- ショップで置き物・設計図を買う → **注文の列** に並ぶだけ。場所は住民が決めて、資材を運んで建てる。
- カメラの「おまかせ」：できごとの場所へゆっくり移る。
- 使われなかった遊び（日替わりのおねがい・目標・くじ・ひみつ）は **コードを残してゲームから外した**（ブランチに残す）。
  「作ったけど遊ばれない物」は思い切って外す。

## 2. 作業の手順メモ（この環境）
- GitHub は REST だけ使える（GraphQL は不可）。PR 作成：`gh api -X POST repos/a-ayumi/PENWorld/pulls -f title=... -f head=<branch> -f base=main -F body=@pr.md`。マージ：`gh api -X PUT repos/a-ayumi/PENWorld/pulls/<N>/merge -f merge_method=merge`（ユーザーが自動マージを許可済み）。
- main は ruleset `protect-main`（削除・force push 禁止）。作業はブランチを切ってから。
- 1 ブランチだけ clone されているので、push のあと Stop フックの誤検知が出たら：`git config --add remote.origin.fetch '+refs/heads/<branch>:refs/remotes/origin/<branch>'` → `git fetch origin <branch>`。
- 並行作業のワークツリーは `.claude/worktrees/`（`.git/info/exclude` で無視済み。コミットしない）。
- Playwright：`chromium.launch({ args: ['--use-gl=angle','--use-angle=swiftshader','--enable-unsafe-swiftshader'] })`。描画が遅いので「画面に入る」は 15 秒待つ。早送りだけなら `w.render` と `w.drawHud` を空にすると速い。
- プレビュー（claude.ai の artifact）は `VITE_NO_SW=1 npx vite build --outDir <dir>` の JS/CSS を 1 枚の HTML に埋めて公開している（題名 PULSAR、Google Fonts の link を頭に付ける）。

## 3. 計画 A：HD-2D 風「くっきりモード」
参考：Godot で作られた城下町の見本（描き込んだテクスチャ・長い影・街灯の光だまり・被写界深度・暖色と寒色）。PS1 風の今の見た目は残し、切り替えにする。「HD-2D」は他社の商標なので、中では「HD-2D 風」と呼び、特定のゲームの絵は真似しない。
1. **影**：箱庭の中で太陽/月の光から影を落とす（建物・柱・キャラ。スプライトはアルファの形で影を落とす）。
2. **夜の明かり**：街灯・窓・たき火の光だまり。スマホでは地面に光の円を描いて代用。
3. **仕上げ**：箱庭の中に被写界深度（主人公にピント）・ブルーム・暖色と寒色の色調整・周辺減光。文字はぼかさず、水や光の粒はぼかしの後に描く。
4. **部品テクスチャ**：つなぎ目なしの石畳・草・瓦・壁の正面絵・4×4 の小物シート。画像生成はユーザーに依頼し、取り込み（外側からつながった白だけ抜く → 切り出し → ドット化）を自動化する。
5. **配置と見た目を分ける**：ステージの配置をデータ（JSON）にする。
6. 小物の密度とカメラの角度・画角の調整。キャラの大きさは見やすさと相談。
- 見本：今の画面に後処理だけをかけた比較画像を作った（ぼかし・ブルーム・色調整で空気感は出るが、建物の描き込みはテクスチャが要る）。

## 4. 計画 B：建築をメインに（味方の城と敵の城）
- **味方の大きな城**：仲間モンスターも含めて、1 つの大きな城を育てる。城壁・門・城下町・壁の内側の住む区画・兵舎・見張り台・投石台など。仲間が住む・暮らす・守る・攻めに出る。今の家・建物・村のしくみ（`houses` / `structs` / `calcVillage`）を、城の「区画」と「施設」に広げる。
- **敵の城**：敵も同じしくみで 1 つの城を作る（敵の資材集め・建築・増築・修理）。敵軍は敵の城から出てくる。こちらから攻め込んで、敵の施設をこわせる。
- **はじまりの位置**：2 つの拠点は、最初はマップの両端（例：味方は西の端、敵は東の端）。間の土地を取り合う。
- **流れのイメージ**：資材 → 建築 → 仲間がふえる → 守り（壁・塔）と攻め（遠征隊）→ 敵の城の施設をこわして領地を広げる。人は直接操作せず、せっけいず・方針（守る/攻める/のばす）を選んで見守る。
- 今の `army`（敵軍）・`assignRoles()`（役割）・`marchTarget()`（こわしに行く先）・ロードマップ（#28）の大軍勢を土台にできる。

## 5. 計画 C：マップを分割して、端まで行ったら次のマップへ
- 世界を複数の「区画」に分けてつなぐ。端の見えない境目に入ると、画面をフェードして地名を出し、隣の区画の反対側から出てくる（PS1 時代の箱庭 RPG でよくある方式）。
- 城も区画をまたぐ大きさにできる（城の区画・城下町の区画・壁の外の区画）。味方の城は端の区画、敵の城は反対の端の区画から始まる。
- 実装の方針：今の `loadStage()` を「区画の読み込み」に広げる。見えていない区画のモンスター・建築・敵軍は、粗い計算で時間だけ進める（おかえりレポート #31 の圧縮の考え方が使える）。区画ごとの保存、隣の区画の情報、ミニマップ。
- 背景：デジタル空間の雰囲気（PS1 期のデジタル世界・プリレンダ風の背景・格子と浮かぶキューブ・空のグラデーション）を参考にするが、**既存作品のキャラ・地名・背景・ロゴは使わず、すべてオリジナル**で作る（CLAUDE.md のルール）。
- 参考：PS1 の箱庭 RPG は、固定カメラのプリレンダ背景の上をキャラが歩き、見えない境目でフェードして隣のエリアへ移る作り（The Map Is a Painting / TCRF の解説より）。

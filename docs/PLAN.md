## 2. 作業の手順メモ（この環境）
- GitHub は REST だけ使える（GraphQL は不可）。PR 作成：`gh api -X POST repos/a-ayumi/PENWorld/pulls -f title=... -f head=<branch> -f base=main -F body=@pr.md`。マージ：`gh api -X PUT repos/a-ayumi/PENWorld/pulls/<N>/merge -f merge_method=merge`（ユーザーが自動マージを許可済み）。
- main は ruleset `protect-main`（削除・force push 禁止）。作業はブランチを切ってから。
- 1 ブランチだけ clone されているので、push のあと Stop フックの誤検知が出たら：`git config --add remote.origin.fetch '+refs/heads/<branch>:refs/remotes/origin/<branch>'` → `git fetch origin <branch>`。
- 並行作業のワークツリーは `.claude/worktrees/`（`.git/info/exclude` で無視済み。コミットしない）。
- Playwright：`chromium.launch({ args: ['--use-gl=angle','--use-angle=swiftshader','--enable-unsafe-swiftshader'] })`。描画が遅いので「画面に入る」は 15 秒待つ。早送りだけなら `w.render` と `w.drawHud` を空にすると速い。
- プレビュー（claude.ai の artifact）は `VITE_NO_SW=1 npx vite build --outDir <dir>` の JS/CSS を 1 枚の HTML に埋めて公開している（題名 PULSAR、Google Fonts の link を頭に付ける）。

## 5. 計画 C：ステージをつなげて 1 枚の広いマップに（区画切り替えはしない）
- **方針の変更**：区画に分けて画面を切り替える方式は、城を建てる・攻める・守るがやりにくくなるのでやめる。いまの 7 ステージ（森・砂丘・入り江・雪原・回路峰・かざん・いせき）を、地続きの 1 枚の大きなマップとしてつなぐ。
- **配置の例**：中央に森、東西南北と四隅にほかのステージ。ステージの境目は地形がなだらかに混ざる帯（草→砂、砂→さんごの浜、など）。味方の城と敵の城は、マップの両端（計画 B）から始まる。
- **ワープ**は、別のステージへ行く機能から「遠くの場所へのファストトラベル」に変える。今の `stageIndex` は「いまいる地方」（バナー・天気・BGM・村の名前の切り替え）として残す。
- **実装の方針**：
  - 地形の高さ・障害物・小物を、地方ごとの関数をつないだ 1 つの `heightAt(x, z)` / 障害物の表にまとめる。
  - 広いので、地形は 区画（例 20×20）ごとにメッシュを分け、カメラの近くだけ表示する（遠くは霧で隠す）。小物は InstancedMesh。
  - 生き物の AI・建物・資材・敵軍は 1 つの世界で動く。遠くの生き物は更新の頻度を下げる（性能）。
  - 保存は地方ごとではなく世界全体。古いセーブ（stage ごとの家・建物）は、その地方の位置に移して読み込む。
- **背景**：デジタル空間の雰囲気（PS1 期のデジタル世界・格子と浮かぶキューブ・空のグラデーション）を参考にするが、既存作品のキャラ・地名・背景・ロゴは使わず、すべてオリジナルで作る（CLAUDE.md のルール）。

## 6. 計画 D：ステージの中をもっと入り組んだ形に（冒険感）
- **通れない地形を立体的に**：崖と段差（登れない高さ・坂でつながる高台）、深い森（木が密集して通れない帯）、岩場・岩壁、海と入り江、川（はしか浅瀬だけ渡れる）、谷・洞窟の入口風の切り通し。
- **道と行き止まり**：道は くねって分かれ、行き止まりの先に たからばこ・資材の山・めずらしいたまご など「行ってみたくなる」ご褒美を置く。高台からの見晴らし、川の向こうの見えている場所など。
- **移動とのつながり**：今の `moveTo()` のよけ方とひっかかり対策では、入り組んだ地形を遠回りできない。地形を格子（例 0.5 マス）で「通れる/通れない」にして、A* などの道さがしを入れる（計算は目的地が変わった時だけ、結果は使い回す）。泳げる・浮ける種族は水を通れる、などの例外も格子に持たせる。
- **城・建築との関係**：城壁や建物も同じ格子に「通れない」として書き込み、敵軍は門を通るか壁をこわす道を選ぶ。建てられる場所は、平らで通れる所だけ。
- **見た目**：崖の断面（地層の色）、川の流れ（計画 A・#27 の水面）、森のかたまりの影。かいたく（広さ）・ステージ連結と一緒に作る。

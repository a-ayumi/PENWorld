# 作成技法まとめ：Three.js で作る「PS1 風 2.5D 箱庭」と「手のひらの 3D デバイス」

このプロジェクト（PULSAR）で使った技法を、別の作品にも流用できる形でまとめたもの。
コードの実例はすべてこのリポジトリにある（ファイル名を併記）。

---

## 0. 全体の構造（2 層レンダリング）

```
[外側] 机の上の 3D 本体（高品質：PBR・影・ボケ・ブルーム）      src/main.ts, device.ts, scene.ts
   └ 液晶面のテクスチャ = ↓ の出力
[内側] 320×240 の箱庭（低品質：PS1 風）                          src/world/*
   RenderTarget(320×240) → 仕上げシェーダー(ディザ+減色+HUD) → RenderTarget → 液晶 or 全画面
```

- **外は今っぽく、中はレトロに**。同じ renderer で 2 つのシーンを描き、内側は `WebGLRenderTarget` に描いてテクスチャとして外側に貼る。
- 内側の最終テクスチャは「本体の液晶」にも「全画面（画面に入るモード）」にもそのまま使える。
- 全画面時は外側の描画を止め、フルスクリーン板ポリ 1 枚だけ描く → スマホでも軽い。

## 1. PS1 風の見た目（src/world/psx.ts）

| 要素 | やり方 | ポイント |
|---|---|---|
| 低解像度 | 320×240 の RenderTarget、`NearestFilter` で拡大 | 拡大時にぼかさないのが最重要 |
| 頂点スナップ（ポリゴンのカクつき） | `onBeforeCompile` で `#include <logdepthbuf_vertex>` の直前に `gl_Position` をクリップ座標で格子に丸める | 標準マテリアル・Sprite・Points 全部にこのフックがあるので 1 関数 `psx(material)` で済む。`customProgramCacheKey` も設定する |
| 15bit カラー + ディザ | 仕上げパスで sRGB に戻し、4×4 Bayer 行列でずらしてから 31 段階に量子化 | 量子化は**リニアではなく sRGB 空間**で行う |
| Gouraud（頂点ライティング） | `MeshLambertMaterial` を使う | PS1 らしい「面のつなぎ目がぼんやり光る」質感 |
| テクスチャ | 64px 程度を手続き生成、色数を絞る、ミップマップ無し | `textures.ts` の `speckle()`（2px ブロックの色ノイズ）が万能 |
| フォグ | `THREE.Fog` を近め（14〜34）に | 遠景を隠す＋空気感。背景色もフォグ色に揃える |
| アフィン（遠近無補正）テクスチャ | 今回は未実装 | WebGL2 では `noperspective` が使えないので、uv×w を渡して fragment で割る方式が必要 |

参考：Three.js 公式の `RetroPassNode`（WebGPU/TSL 版。頂点スナップ+アフィン+低解像度）を使う手もある。

## 2. 2.5D キャラ（src/world/sprites.ts, monsters.ts）

- **キャラは 2D、世界は 3D**。`THREE.Sprite` をカメラ正対で立て、`center.y` を足元に合わせて `position.y = 地面の高さ`。
- **`alphaTest: 0.5` + 不透明描画**（transparent にしない）→ 深度で前後関係が正しくなり、ソートの問題が出ない。
- **ドット絵はコードで描く**：Canvas に楕円・多角形で描画 → アルファを 2 値化 → 1px の色付きアウトラインを自動で付ける（`pixelSprite()`）。
  - 塗りは「影色 → 本体色を少しずらして → ハイライト」の 3 段（`blob()`）で立体感が出る。
- **ポーズ表で全コマを生成**：`{bob, sq(つぶれ), step(足), eye, mouth, lean, flap}` を 12 個並べ、1 つの描画関数から idle/walk/happy/eat/sleep/attack/hurt を作る。新モンスター追加は描画関数 1 つだけ。
- 左右反転はアトラスの 2 行目に反転版を焼いておき、UV オフセットで切替（`SpriteAnim`）。
- 進化はテクスチャの `image` を差し替えるだけ（`setSheet()`）。
- 影は丸い半透明の板。ジャンプの高さに応じて縮める。
- 1 ドットの大きさを揃える：全モンスター同じキャンバスサイズ（34×32）で描き、`height` で全体の大小を決める。

## 2.4 ドット絵のディテールを上げる

- 描画関数はそのまま（34×32 の座標）で、`g.scale(2, 2)` して **2 倍の 68×64 で焼く**。丸や斜めがなめらかになり、0.5 刻みの小さなハイライトも置ける。
- **自動陰影**（`pixelSprite` の `shade`）：左上のふち = 明るく、右下のふち 2px = 暗く、その内側は市松模様の網点で影をぼかす、足元は少し暗く。全キャラに一括で立体感が出る。
- **色付き輪郭**：輪郭の色を「隣の色を暗くしたもの + 基本の輪郭色」にすると、黒一色より柔らかく、ドット絵らしい仕上がりになる。
- 細かくしたら**描画解像度も上げる**：箱庭 480×360、HUD 320×240、出力 960×720 にして、両方が整数倍で拡大されるようにする（文字のドットが不揃いにならない）。

## 2.5 3D モデル版のキャラ（src/world/models.ts）

- キャラは 2D ドット絵から**ローポリ 3D**に置き換え可能。`MonsterModel` は `SpriteAnim` と同じ口（`sprite` / `facing` / `play` / `update` / `setHeight` / `dispose`）なので、World 側はほぼそのまま。
- 部品は球（18×14 分割）・円柱・円錐・箱の組み合わせ。足や腕は**付け根のピボット Group** に入れておくと、回すだけで歩きや腕振りになる。
- 手続きアニメ：歩き = 弾み + 足の前後 + 左右の揺れ、食べる = うなずき、眠る = つぶれ + 目を閉じる（目の scale.y を 0.1）、攻撃 = 前傾、やられ = のけぞり + 全マテリアルを赤く発光、まばたきは一定周期で目を細く。
- 向きは**前フレームとの位置の差**から求めて体ごと回す（World は x 方向の facing しか持っていなくてよい）。止まっている時はカメラ寄りに向けると表情が見える。
- PS1 っぽさは `psx()`（頂点スナップ）とディザでそのまま残る。分割数を上げても、低解像度 + 頂点スナップで「当時のポリゴンキャラ」の見た目になる。
- **シルエットのオリジナリティ**を確認する：単純な形（カプセル + バイザーなど）は既存のキャラに似やすい。頭と胴を分ける、特徴的な部品（歯車の耳・プラグのしっぽ・ゴーグル）を足す。

## 3. 箱庭のステージ（src/world/stages.ts）

- **四角い島がデジタル空間に浮いている**構図：地形グリッド（20×20）+ 側面に地層テクスチャを貼った Box + 下に光るグリッドと漂うキューブ。
- 地形は `heightAt(x, z)` 関数 1 つで定義し、メッシュ生成とキャラの接地の両方に使う。
  - 端へ向かって平らにする `edge()` で、側面の Box とつなぎ目が出ないようにする。
  - **地面は土台の上面より下に沈ませない**（`max(0.24, h)`）。沈むと土台の上面が見えて「穴」に見える。
- 小物は**ローポリ + flatShading**（木 = 円柱 + 正二十面体、結晶 = 八面体を縦に伸ばす、など）。
- **「前の時代の痕跡」**（遺跡の柱、雪に埋もれたアンテナ塔）を置くと世界に物語が出る。
- 空はシェーダーのグラデーション球（夜は星、雪原はオーロラ）。
- 置き場所は乱数シード固定の `placer()` で、中央と既存の障害物を避ける。
- ステージごとに「食べ物の実る場所（foodSpots）」「住んでいるモンスター（residents）」を持たせる。
- **水場**は `water: true` の円形障害物 + 波打つ水面シェーダー。浮く種族（`float`）だけが水の上に入れる。地形は水場の中を土台の高さまで下げ、水面を少し上に置く。落ちた食べ物が水に入ったら岸へずらす。
- 凍った湖のように「見た目だけ違う床」は障害物にせず、平らにした地形の上に板を 1 枚置くだけでよい。
- **溶岩・遺跡のステージ（src/world/stages2.ts）**：新しいステージは別ファイルにして `STAGES` の後ろにつなぐ（ステージ番号で引く表は `WEATHER_W` / `STAGE_EGGS` / `STYLES` / 村の名前の 4 つ）。
  - 溶岩は水場と同じ `water: true` に `lava: true` を足した円形障害物（越えられるのは浮く種族だけ）。川は小さな円を数珠つなぎにし、模様は**ワールド座標**で引くので、つなぎ目に境目が出ない。夜は溶岩の明るさと、下に敷いた加算合成の光る円板で照らす（本物のライトは増やさない = マテリアルの再コンパイルを避ける）。
  - 噴煙は `Points` の頂点シェーダーで `fract(time + seed)` を使い、上昇・拡大・色（橙 → 灰）・透明を 1 パスで出す。
  - 遺跡の夜の文様は、昼用のテクスチャ（`map`）と同じ図柄を黒地に描いた `emissiveMap` を組にし、夜に `emissiveIntensity` を上げるだけ。図柄は升目に描く幾何学（入れ子の四角・ひし形・直角のうず・段）で、実在の文字や模様を使わない。
  - 霧は `Stage.fogRange`（フォグの近さ）+ 地面近くを流れる半透明の板。浮かぶ石板は更新で上下・回転させ、地面に丸い影を置く。夜のヤミカゲの数は `Stage.shadows`。

## 4. 生き物の AI（src/world/World.ts）

状態機械 + 欲求（おなか・げんき）+ 性格（calm / wild）で「勝手に暮らしている」感じを出す。

```
idle ─think()→ wander / seek(食べ物) / sleep / hunt(獲物) / happy
hunt → 近づいたら fight（両者を fight にする）
fight → 攻撃のクールダウンごとに attack() → HP 0 で defeat()
seek → eat → happy        sleep → 回復して idle
```

- `think()` の優先順：野生なら獲物探し → ペットなら近くの敵に挑む → おなかが空いたら食べ物 → 眠い/夜なら寝る → ランダム行動。
- **障害物の回避**：進行方向の前方にある障害物から横方向にずれた分だけ押し返す簡易ステアリング（`moveTo()`）。これが無いと木に引っかかって永遠に止まる。
- 戦闘中の相手にペットは割り込める（野生は待つ）。
- 倒れたペットは死なずに「たおれた」→ 回復。野生は消えてデータの粒になり、時間をおいて再出現。
- **ダメージ数字・HP バーは 3D ではなく HUD に描く**：`Vector3.project(camera)` で画面座標にしてから 320×240 のキャンバスに描画 → 文字がくっきり、実装も簡単。
- 演出：攻撃は前に突き出す（lunge）、被弾はノックバック + hurt コマ、会心は数字を大きく黄色に。

## 4.5 育成の仕組み（間接的な関わり）

- **直接命令しない**：人ができるのは食べ物・置き物を「用意する」ことだけ。モンスターは `think()` の中で、それを使うかどうかを自分で決める。
  - なえ → 60 秒で木になり、食べ物の実る場所が増える。ボール → 元気な子が勝手に蹴って遊ぶ。たき火 → 夜や眠い時にそばで眠る。おまもり → ノイズの索敵範囲と再出現が減る。
  - 家づくり支援：ざいもくセット → 見ている所に木 3・石 2 をまとめて置く（`spawnResource(..., force)` で上限 +8 まで）。だいくどうぐ → 半径 6 の家は資材 1 回で 2 個分、毎秒 0.8 ずつ自動修理。まもりのさく → 半径 3.2 の家のダメージ半分。どれも `nearItem(kind, x, z, r)` で判定。
- **増えた量をメッセージに**：行動の前の値を控えておき、終わった時に `delta('おなか', 後 - 前)` で「おなか+25」の形にして `say()` に連ねる（0 の項目は出さない）。眠りは `sleepFrom` で入眠時の値を保存。
- **進化分岐**：食べ物とできごとで「ちから / まもり / こころ」の傾向が積み上がり、経験値がしきい値を超えた時に一番大きい傾向で進化先が決まる（`BRANCH`）。
- **仲間**：穏やかな野生がペットのそばで過ごす・守ってもらうと仲良し度が上がり、100 で仲間に。仲間はペットについて回り、バトルでは相手を取らずに横から加勢する（`assist`）。
- **たまご**：ペットと仲間がどちらも成長期以上・元気・ごきげんで近くにいると、一定間隔で抽選。たき火のそば・夜は確率アップ。ふ化した子は小さく生まれて少しずつ大きくなる（`grow`）。
- **コイン**：勝利・食事・進化・誕生・仲間入り・見守り時間で増え、ショップで使う。
- **セーブ**：生き物・置き物・たまご・コインを JSON で localStorage に保存。

## 4.6 人間側の場所ときせかえ（src/places.ts, device.ts）

- 背景は「壁の絵（キャンバスで手描き）+ 本体の下の面のテクスチャ + 動き」の 3 点セット。時間帯で空の色を変えて描き直す。
- 電車は窓を `destination-out` で透明に抜き、奥に流れる街並みと速く流れる電柱の 2 枚を置いて視差を出す。通学路は景色と地面を流しつつ、本体を歩くリズムで揺らす。
- 背景は最初から少しぼかして描く（`ctx.filter = blur()`）→ スマホの低画質（被写界深度なし）でもピントが本体に合って見える。
- 本体の柄は `MeshPhysicalMaterial` の色・柄テクスチャ・透過（transmission）を差し替えるだけ。プレートの文字色も柄に合わせて描き直す。
- **カメラを動かしたら被写界深度のピント距離も必ず合わせる**（ずれると本体がぼやける）。

## 4.7 生態系：1 匹ずつの進化・家づくり・天気

- **進化は 1 匹ずつ**：全員が経験値と「ちから / まもり / こころ」の傾向を持つ。戦って勝つ = ちから、資材を運ぶ = まもり、遊ぶ・たき火で眠る = こころ。さらに生まれつきの性格（`bias`）と気まぐれを足して進化先を決めるので、同じ種族でも別の姿になる。ペットだけは人が与えた食べ物どおりに育つ。
- **じゃれあいバトル**：おとなしい子どうしがときどき力くらべ。負けても消えず（`spar` フラグで faint 扱い）、両方に経験値が入る。
- **家づくり**：木と石が木や岩のそばに落ちる → 家の無い子は空き家に住みつくか新しく建てはじめる → 拾って運ぶ（頭の上に資材を乗せる）→ 資材 2 個で土台、5 個でかべ、8 個で屋根。屋根の色は建てた種族の色。
- **こわす / こわされる**：ゴウガン（家をこわしたがる）やひのこの日の敵が家を攻撃。持ち主がかけつけて戦う。hp が 0 になると 1 段階くずれて資材がちらばり、また拾って直す。ひのこの日は木の家が少しずつ焦げる。
- **天気**：1 つの Points（1500 粒）をカメラの周りに置き、シェーダーのモードで 雨（細い線が速く落ちる）/ 雪（揺れながら落ちる）/ ひのこ（加算合成で昇る）を切り替える。光の強さ・霧の色・空の暗さも天気で変える。雨の日は実が多く落ち、みんな家に入る。雪の日は雪の種族が元気。

## 4.8 技（スキル）の演出

- 種族ごとに技を 1 つ（名前・色・演出の種類・威力）。演出は 6 パターンを組み合わせて使い回す：弾（shot）、その場の衝撃（burst）、突進（dash）、空から降る（rain）、回復（heal）、地面の波（wave）。
- 技を出すと、メッセージ欄に「○○の △△！」と出す（仲間がからむ時と、カメラの近くの時だけ。出しすぎるとうるさい）。弾は通り道に光の粒を残し、当たると技の色でダメージ数字を `30!!` のように出す。強い段階の技はカメラを少し揺らす。
- 「遅れて起きること」は `after(秒, 関数)` に積んでおき、毎フレーム時間を減らして実行する（弾が届いてから当たる、波が広がってから当たる、など）。
- 人は直接技を命令しない。バトル中に「バトル」アイコンを押すと「おうえん」になり、次の攻撃で技を出す。

## 5. HUD（World.drawHud）

- 320×240 のキャンバスを毎フレーム描き、仕上げシェーダーで最後に合成（ディザの**後**に乗せるので文字が崩れない）。
- PS1 時代っぽい**青グラデ + 白い 2 重枠のウィンドウ**、上下 4 つずつのアイコン帯、ステージ名のスライドイン。
- 日本語のドットフォントは Google Fonts の **DotGothic16**（フォールバックに monospace）。

## 6. 外側の「手のひらデバイス」（src/device.ts, scene.ts, main.ts）

- 本体は `ExtrudeGeometry`（角丸形状 + ベベル）+ `MeshPhysicalMaterial`（clearcoat・sheen）でプラスチック感。
- ボタンは円柱 + 潰した球のキャップ。押すと沈み、本体がばねで少し傾く。
- 環境：`RoomEnvironment` の PMREM で映り込み、手続き生成の木目の机、玉ボケを描いた壁、ほこり粒子。
- 時間帯（朝/昼/夕/夜）で光・壁・露出を切替（`MOODS`）。
- 仕上げ：Bokeh（被写界深度）+ UnrealBloom（しきい値高め）+ ビネット/粒子/色調整 + `NeutralToneMapping`。
  - **カラー液晶は MeshBasic で少し暗く**（#c4c4c4）しないとブルームで白飛びする。
- 「画面に入る」：カメラを液晶の正面まで補間で寄せ、到着したら全画面描画に切替。戻るときは逆再生。

## 6.5 視点の切り替え（主人公視点）

- 同じシーンをカメラの置き方だけ変えて描くので、**重さはほぼ変わらない**。
- ペットの向きは前フレームとの位置の差から求め、カメラの向きはそれを少し遅れて追いかける（酔いにくい）。
- うしろ視点：ペットの後ろ 3.3・高さ 2.0 から、ペットの少し前の低い所を見る。`camera.near` を 1.2 にして、カメラの直前の木や仲間で画面がふさがらないようにする。カメラは箱庭の外に出さない。
- 目線視点：目の高さに置き、描画のときだけ自分の体と影を隠す。
- どの視点でも地面より下にカメラが潜らないように `heightAt` で持ち上げる。

## 6.55 2 本指のカメラ操作

- `pointerdown/move/up` で指を Map に入れて数える。2 本になったら本体の傾け操作をやめ、2 本の距離の比 = ズーム、中点の移動 = パン、にする。
- 1 本指のタップは「指を離した時、ほとんど動いておらず短い時間だった」ら判定する。ピンチの直後はタップにしない（誤タップ防止）。
- みおろし：パンは見る場所を前後左右にずらす（ペットを追いつつ、ずらした分を足す）。うしろ：パンは回りこみ（向き）と高さ、ズームは距離。めせん：ズームは画角（望遠）。

## 6.6 タッチ操作

- 液晶の中の HUD は 320×240 のキャンバスなので、タップ位置をその座標に直して当たり判定する。
  - 本体ビュー：液晶メッシュにレイを飛ばし、当たった位置の `uv` を使う。
  - 全画面：表示している板（4:3）の範囲から `uv` を計算する。
- ショップは「1 回目のタップで選ぶ、同じ項目をもう 1 回で買う」にすると誤タップで買わない。

## 7. スマホ・PWA

- 本体ビューは**液晶とボタンが画面いっぱい**になるようにカメラ距離を決める（本体の縁や背景は画面外にはみ出してよい）。縦画面では液晶が横幅のほぼ全体になる。


- 画質「低」：ボケとブルームを切り、ピクセル比を 1.5 まで。スマホは既定で低。
- 内側の世界は常に 320×240 なので、画面サイズに関係なく負荷が一定。
- `vite-plugin-pwa` の `registerType: 'prompt'`（プレイ中に勝手に更新しない）。
- 埋め込みプレビュー用に `VITE_NO_SW=1` で SW 登録を外せる。

## 8. ハマりどころ

- **初回フレームの dt がマイナス**になることがある → `clamp(dt, 0, 1/20)`。マイナスだとボタンの押し込み値が増え続けて本体に埋まった。
- RenderTarget への描画ではトーンマッピング/色空間変換がかからない → 仕上げシェーダーで自分で sRGB⇔リニア変換。
- `CanvasTexture` の HUD は色空間を指定しない（sRGB のまま合成したいので）。
- 頂点スナップは `customProgramCacheKey` を付けないと、同じ種類の通常マテリアルとシェーダーが混ざる恐れがある。
- 二つの障害物の間など、簡易ステアリングでは抜けられない場所がある → 本格的にするなら格子上の A*。

## 9. 確認方法

- `window.__pulsar.world` から `run(i)`（アイコン i を実行）、`update(1/30)` を回して**早送り**し、`say` を横取りしてメッセージを記録 → バトル・食事・進化が最後まで通るかを自動確認できる。
- 見た目は Playwright で 1280×800（デスクトップ）と 390×844（スマホ）を撮影して確認。
- ヘッドレスのソフトウェア描画は遅いので、時間の進み方の確認は早送りで、見た目の確認はスクリーンショットで、と分ける。

## 10. オリジナリティのルール

雰囲気の参考にした作品はあっても、**キャラ・ステージ・ロゴ・UI・音はすべてオリジナル**で作る。
取り入れるのは「PS1 時代の表現技法」「箱庭で生き物が暮らす育成の手触り」のような一般的な要素だけ。

## 建物・村・敵軍（`structures.ts` + `World.ts`）
- **建設現場方式**：建物は `Struct`（`mats` / `need`）。せっけいずを買うと `planStruct` が「見ている所」のまわりの空き地に現場（`mats=0`）を置き、手の空いた子が `openSite()` で最寄りの現場を選び、資材を拾って `build` 状態で運ぶ。建設中は完成モデルを縦に縮め（`0.3 + 0.7 * 進み具合`）杭を立てるだけで、段階ごとに作り直す（`q`）。
- **当たり判定**：`obstacles()` に建物の円を足す。へいは円を並べた輪で、手前（+z）に 1 つ抜けた門を残す。はし（`bridge`）は水場の障害物を `obstacles()` から外すだけ。
- **機能**：はたけ = 22 秒ごとに食べ物、いど・おしろ = 近くの味方を回復、ゆりかごごや = たまご確率 ×1.8、みはりとう = 1.8 秒ごとに 7.5 以内の敵へ弾（`fx` のスプライト + `after()` でダメージ）。
- **村のにぎわい**：家（完成）と建物の点数の合計 `vScore` → レベル `vLv`（4 / 9 / おしろ付き）。名前はステージごと。収入と仲良し度に効く。
- **敵軍**：`Army { phase: warn → on }`。`army` フラグ付きの敵は `march` で `marchTarget()`（最寄りのこわせる建物）へ進み、近くに味方がいれば戦う。再出現しない・エネルギーが減らない。数は村の点数、強さは 回数 ×0.15 で増え、3 回に 1 回ボス（ゴウガン）。
- **セーブ**：`structs` を保存。読み込みは `isStructKind` / `num` で検査する。

## 村の施設・祭り（`structures.ts` の新しい 6 種 + `World.ts`）
- **名前つきの部品で動かす**：モデルは箱・筒・円すいの組み合わせだけ。動かしたい部品に `name` を付け（`blades` 羽根 / `beam` 灯台の光 / `jet` 噴水 / `swing` ブランコ / `flag` / `lit` 窓 / `snow` 雪 / `chimney` けむり）、`mountStruct` が一度だけ集めて `userData.parts` に入れる。毎フレームの `traverse` を避けるため。
- **窓の光と雪の屋根**：`lit` は `MeshBasicMaterial` で、色を「点灯」と「消灯」の 2 色にして夜・雨・雪で入れ替える（新しい `PointLight` を足さないので画質「低」でも軽い）。雪の屋根は白い円すい/板をふだんは `visible = false` で埋めておき、雪の天気の間だけ見せる。
- **建設中の足場**：完成モデルを縦に縮めたまま、`buildScaffold()` の杭・横木・ななめの木・資材の山・旗を重ねる（高さは進み具合で伸びる）。
- **効果は「近い物を数える」**：ふんすい/いどの回復は 1 秒ごと、とりでの攻撃力は与ダメージの計算（`power(c)`）で近さを見る、とうだいは `callArmy` の予告時間と `guardRange` を足す。水べ判定は `stage.obstacles` の水場との距離。
- **やどかりの行商**：敵でも味方でもない小さな見せ物（`Creature` ではなく `THREE.Group` + 影）。いちばへ歩いてきて、たまごか特別な食べ物を置いて帰る。
- **祭り**：`Festival`（中心・のこり時間）を持ち、参加する子は `dance` 状態で中心まわりの輪を `dAng` で回りながら拍子ではねる。開始の 14 秒間は手が空いた子を 1 秒ごとにさそう。敵軍が来たら中断。紙ふぶきは重力 0 のスプライト。

## 動き（アニメーションの足し方）
- **ドット絵はそのまま、スケールで命を足す**：`SpriteAnim` はフレーム切り替えだけなので、毎フレーム `setHeight()` のあとに `sprite.scale.x/y` へ ぷにぷに係数を掛ける。足元が基準点なので伸び縮みしても地面から浮かない。歩き = `|sin|` で上下 + `cos(2θ)` で縦横、息 = ゆっくりの `sin`、ジャンプ = 上昇で縦に伸び下降で戻り、着地で `squash` を立てて減衰させる。
- **作業の間（ま）**：資材を運び終えてすぐ反映せず、`work` 状態で 1.1 秒はねて火花を出し、資材をかなづちのようにふってから `finish()` を呼ぶ。完成した建物は `userData.pop` で 0.55 秒だけ縦に ぽよん。
- **ヒットストップ**：当たった瞬間に `update()` の `dt` を 0.2 倍にして 0.06〜0.15 秒だけ遅くする（時間を止めるより自然）。
- **環境の生き物**：`ambient` はビルボードのスプライトを sin / cos で漂わせるだけ。昼は ちょうちょ（羽ばたきは scale.x）、夜は ほたる（scale で明滅）、雨・ひのこでは隠す。

## 系統・進化の枝分かれ・たまご（`families.ts` + `monsters.ts`）
- **パーツ指定で描く**：`critter(g, pose, frame, look)` は 体の形（四つあし / 二足 / 鳥 / かたまり）に、しっぽ・つばさ・耳・角・よろい・ゴーグル・歯車・たてがみなどを重ねるだけ。1 種 = 1 行の `Look` なので、40 種ぐらいなら絵を描かずに増やせる。足もとは y=30、右むき、大きい子は左へずらして枠からはみ出さない。
- **枝分かれの型**：赤ちゃん → 成長期 A（ちから）/ B（まもり・こころ）→ 成熟期 A / B → 完成期 1 種。`EVOLVE` は「種族 → ちから/まもり/こころ → 次の種族」の表で、`CHAINS` から自動で作る。昔のめばえの木は `BRANCH` のまま共存する。
- **たまごの系統**：ふつうの卵は親の種族の子（`inherit`）。系統の卵は赤ちゃん（`BABY`）が生まれ、そこから系統の木を進む。親の系統を 6 割で受けつぎ、ときどきその場所らしい系統（`STAGE_EGGS`）に変わる。

## ずかん・役割分担・世代交代・かいたく
- **ずかんは「1 秒ごとの棚卸し」**：登録の入り口をあちこちに作らず、全生き物を眺めて `dex[id] = max(今の値, 見た / 仲間)` にする。新規はまとめて 1 通のメッセージにして、スパムにならないようにする。報酬は閾値の配列を `dexClaimed` で進めるだけ。画面は HTML（canvas に スプライトの 1 コマ目を貼る）なので、タップ判定を自作しなくてよい。
- **役割は「足りない物から数える」**：役割の枠（はたけの数・見張り台の数）を先に数え、性格ごとの希望順に空き枠へ入れる。足りなくなれば `free` に戻る。動きは新しい AI を足さず、既存の `work`（作業の間）・`wander` / `idle`（見まわり）・`hunt`（索敵の範囲だけ広げる）に乗せる。
- **世代交代は「同じ Creature を作り替える」**：ペットは `this.pet` として多くの場所から参照されるので、別の個体に差し替えず、`sp` / `grow` / HP を赤ちゃんに戻す。お墓は置き物（`memorial`）として保存される。
- **箱庭の広さは変数**：`SIZE` / `HALF` を `export let` にして（ESM のライブバインディング）、ステージを作る直前に `setLandSize()`。地形の分割・土台・端のなだらかさは `SIZE` 参照なので自動で広がり、小物の数だけ `dens()` で面積に合わせる。

## 置き物とショップ（src/world/items.ts, shop.ts）

- 置き物のモデルは箱・筒・円すい・二十面体だけ。部品を名前つきで `userData` に持たせ、`tickItem()` が毎フレーム回す・ゆらす（風・夜・近くの作業で変化）。
- 光源（PointLight）は画質「低」では作らない。買った時は上から落とす（バウンド + つぶれ + 火花）と、コインが渦を巻いて吸いこまれる。
- ショップは HUD に 9×9 のドット絵アイコン・カテゴリのタブ・2 行の説明・買えない理由（色分け）を描く。描画とタップ判定は同じ寸法定数を使う。
## 隠し進化の作り方（src/world/secrets.ts）

- 見た目・技・条件を 1 ファイルの表にまとめ、monsters.ts は `SECRET_FORMS` から `LOOKS` / `NEW_SKILLS` / `SPECIES` を足すだけ。
- 条件は `(ctx) => boolean` の純粋関数 3 つ。ctx（時間帯・天気・近くの建物・世代・食べた物…）は World が進化の瞬間に作る。
- 同じ関数でヒントも出す：条件を 1 度でも満たすと、その行だけがずかんに増える。
- できごとは `dwell`（秒）だけ条件が続くと 1 度だけ発動。光の粒は重力 0 のスプライト、にじは頂点カラーの半円リング。
## キャラの見た目：個体差・色ちがい・表情・進化の演出（`monsters.ts` / `sprites.ts`）
- **スプライトは「種族 × 見た目 16 種」だけ**：個体ごとのシードを 8 種の見た目（ふつう / 色相 ±11° / ぶち / しま / そばかす / ほっぺ / しま+色相）に量子化し、色ちがいを +8 して `sheetFor(id, vk)` で 1 回だけ焼く。個体ごとに焼くとキャッシュが爆発するので、量子化がいちばん大事。
- **もようは「描き終えた絵」に後から重ねる**：描画関数は `Geom`（からだ・あたまの中心と半径・口の位置・からだの色）を返す。`decorate()` は `getImageData` で絵を読み、からだの色（誤差 44 以内）の画素にだけ、ぶち（だ円）・しま（斜めの帯）・そばかす（あたまの点）・ほっぺ（だ円）を重ねる。目・口・かざりの色は一致しないので崩れず、53 種ぜんぶに同じ処理で効く。色相ずらしも同じパスで、白っぽい子は色ちがいの時に彩度を足し、明るさを少し落とす（そうしないと色が乗らない）。
- **表情は「目・口・しるし」の 3 点**：`eyes()` に sleepy（半目）/ worry（まゆが下がる）/ hungry（うるうる）を足し、口は 6 種（とじる・あける・にっこり・こまり・よだれ・くいしばり）、しるし（z・ハート・# ・あせ・よだれ）は色相ずらしを受けないよう最後に重ねる。昔の描き方の子（目が特殊）には `legacyPose()` で近い目・口に置きかえて渡す。状態から表情を選ぶのは World の `faceOf()` だけ。
- **進化の演出**：`SpriteMonster.silhouette()` が白一色の 1 コマのシートに差しかえる（`source-in` で白く塗りつぶす）。ちかちか点滅 → 白がふくらむ → 新しい姿のシルエット → ちぢんで本来の絵、をスケールだけで見せる。ドット絵の切りかえは `setSheet` なので軽い。3D モデル・見えていない子は演出なしで即切りかえ。
- **ずかん用の絵は 1 コマだけ**：`portraitFor()`。シート全体（22 コマ × 2 行）を 60 種ぶん作るとメモリが無駄になる。
- **敵の亜種とボス**：`enemyFor()` がステージの敵をときどき亜種に入れかえ、`armyMember()` / `armyBoss()` が敵軍の編成を決める。ボスは専用の大きな絵（高さ 3 前後）で、`Species.boss` が立っていれば小さな HP バーのかわりに画面上の大きな HP バーを出す。
## 天気と風と水（`fx.ts` + `fxprops.ts`）
- **共通の uniform `fxU` を全シェーダーで共有する**：時間・風・ぬれ・雨・積雪・雲の影・夜・画質（`uHigh`）。値は `World.updateWeather()` が毎フレーム入れるだけ。各ステージの `update(t)` で何も更新しなくてよいので、新ステージは材質を作る時に 1〜2 行足すだけで天気に反応する。
- **標準材質へのパッチ**：`psx(material, { sway, ground, snow })`。`onBeforeCompile` で `begin_vertex` の後に風のゆれ、`emissivemap_fragment` の後に地面（ぬれ・水たまり・波紋）と雪（上向きの面だけ白）、`opaque_fragment` の前に雲の影を差しこむ。`customProgramCacheKey` にオプションを入れる。`psx(m)` だけなら今までどおり頂点スナップのみ。
- **風のゆれは頂点の重み `aFx`**：`swayify(木のGroup)` が各頂点の「Group 内の高さ / 全体の高さ」^1.7 を `aFx.x` に焼く（根もとは動かず先ほど揺れる）。頂点シェーダーは世界座標の風向きの変位を、物の回転・拡大の逆行列で局所に直して足す（木を回しても拡大しても風は同じ向き）。家・建物・キャラは `swayify` を呼ばないのでゆれない（同じ材質を使っていても、`aFx` の無いメッシュは重み 0）。草と花は `grass()` が 1 本の Mesh（三角形の束）にまとめ、根もと 0・先 1 の重みと色のグラデーションを頂点に持つ。
- **水**：`waterSurface({ deep, shallow, rings? })`（CircleGeometry 用）。ワールド座標の格子に量子化した 2 層のさざ波をスクロール、ふちの泡（波にあわせてゆれる）、波の頂にだけ出る**きらめき**（セルごとのハッシュを 0.5 秒ごとに変える）、雨の波紋。浮き物は `floaters(group, pool, 水面の高さ, 'pad' | 'log', 個数)`：上下は頂点シェーダー（`aFx.z`）なので update 不要。
- **雨の波紋は 1 マス 1 個のリング**：`fxRings(xz, マスの大きさ)`。マスのハッシュで中心と位相をずらし、`uRain` が高いほど多くのマスが生きる。地面・水面で同じ関数。しぶきは地面の高さを入れた Points（`WeatherFx.setGround`）を頂点シェーダーの位相で光らせる（CPU 無し）。
- **雲の影**は風で流れる value noise（`uDrift` を風速で積分）を 3 段にまるめた暗がり。**積雪**は `noise < uSnow` のマスだけ白（降るほど広がり、止むと溶ける）。**ぬれ**は全体を暗く、低い所の noise が高い部分を水たまり（青っぽく、空の色を足す）。
- **粒子は強さ（0〜1）で数を出し入れする**：各粒子が持つ乱数 `seed < 強さ` のものだけ描くので、天気が変わる時に自然に入れかわる（`World.wx` が約 4 秒でなめらかに追う）。雨は `LineSegments`（頭が明るく、しっぽが消える。風で斜め）、雪は大きさ 3 段、火の粉はのぼるほど赤く暗く。ひのこの熱ゆらぎは**仕上げシェーダー**で 2px の行ごとに横ずらし（HUD は別サンプリングなのでゆがまない）。
- **空**（`skyDome`）：`uGrey`（くもり・あめの灰色）・`uEmber`（赤）・`uBow`（にじ：太陽と反対がわの 7 色の弧を角度で塗る。向きは出た時に見ていた方向 `uBowDir`）、星は `atan` に時間を足してゆっくり回し、月は球面の接線平面で細い月を描いて空を横切らせる。
- **画質「低」**：`World.setQuality('low')` が `uHigh = 0`（uniform の分岐で風・雲の影・水たまり・波紋・きらめきを飛ばす）、粒子の数を約半分、`fxLod()` で草を約 45%、もやと熱ゆらぎを無効にする。雪の積もりとぬれの暗さは軽いので低でも出す。新しい重い効果は同じように `uHigh` か `World.high` で切れる形にする。
## 仕上げ：軽さ・オフライン・設定（`main.ts` / `shell.ts` / `style.css`）
- **まず計測**：`world.update` と `drawHud` を 150 回まわして 1 回あたりの ms を出す（`performance.now()`）。メソッドを一時的に包んで時間を足し合わせると、どこが重いか分かる。重かったのは `drawHud`（文字の縁取りで `fillText` が 1 文字列 6 回）なので、HUD の再描画を 30 回/秒までにし、`project()` の使い捨て `Vector3` をやめた。`obstacles()` は呼ばれる回数が多い（生き物 1 匹ごとに数回）ので、フレーム番号つきのキャッシュにした。`nearest()` は先に距離（2 乗）で外してから条件の関数を呼ぶ。
- **自動画質**：2 秒ごとの平均 FPS を見て、低い状態が 2 回続いたら 1 段下げる（高 → 低 → ピクセル比 1 → 0.8 → 0.6）。起動直後・裏から戻った直後・長いフレーム（0.5 秒超）は数えない。上げ戻しはしない（行き来を避ける）。手動で「高」「低」を選んだ時は一切触らない。
- **裏に回ったら止める**：`document.hidden` の間はループで即 return。戻ったら `min(1, 離れていた秒数)` だけ `world.update` を 1/15 刻みで進める（大きな dt を一度に入れない）。
- **オフライン**：本体（js/css/html/svg/png）は precache。Google Fonts は precache できないので `runtimeCaching`（CSS は StaleWhileRevalidate、字体は CacheFirst）で、一度見た後はオフラインでも使える。一度も見ていない時は `FONT` / `font-family` の代替フォント。確認は Playwright の `context.setOffline(true)` + リロード。
- **やさしい失敗**：`new WebGLRenderer` を try/catch、`webglcontextlost` で `preventDefault()` して案内を出し `webglcontextrestored` で消す。CSP で inline script が使えないので、起動の見張りは別エントリ `boot.ts`。
- **動きをへらす**：`prefers-reduced-motion` を既定にして、`World.reducedMotion` 一つで ゆれ・フラッシュ・ヒットストップ・ぷにぷに の係数を変える（係数を掛ける 1 行ずつの差分）。

## iPhone のウィジェット（Scriptable、`World.widgetData()` + `public/scriptable/PULSAR.js`）
- **ウィジェットでは WebGL も常時の動きも使えない**（数十 MB の上限、更新は 15 分ほどごと）。そこで箱庭は「背景の 1 枚絵 + 上に置くドット絵」に分ける。PWA 側で生き物・効果・ちょうちょ のスプライトを一時的に隠して 1 回だけ描き、`readRenderTargetPixels` で読む。仕上げシェーダーと同じ計算（sRGB 化 → 4×4 ディザ → 15bit 色）を JS でかけてから JPEG にする。
- **立たせる場所は画面座標で渡す**：生き物の足もとと、空いた地面の点をカメラで `project()` して `u, v`（0〜1）と「1 マスの高さが画面の何割か」`k` を出す。ウィジェットは切りぬき（`cover` + 寄り）と同じ変換で点を移し、`身長 × k` の大きさで奥から順に描くので、遠近がそろう。
- **動いて見せる**：15 分の枠番号を種にした乱数で、居場所とようす（ねる・たべる・いえづくり…）を決めなおす。時刻で 朝・昼・夕・夜 の色をかぶせ、夜は ほたる。送った時にすでに夜なら暗くしすぎない（`night` を引く）。
- **ドット絵は 1 コマ目**：`portraitFor()` はシートがあればその 1 コマ目を切りだす（シート全体を返すと全コマが並んだ絵になる。ずかんも同じ不具合だったので直した）。
- **受け渡しはクリップボード**：`PULSARW1:` + base64 の JSON（約 130 KB）。「Scriptable をひらく」は `scriptable:///run/PULSAR?import=1`。スクリプトは中身を信用せず型と範囲を検査（画像は `data:image/png|jpeg;base64` だけ、URL は https だけ）。Safari のコピーは押した直後しか通らないので、読みこみ待ちの中身は `ClipboardItem` に Promise で渡す。
- **確認**：Scriptable の `DrawContext` / `ListWidget` などを canvas で真似た小さなページで、スクリプトをそのまま動かしてスクリーンショットを撮る。
